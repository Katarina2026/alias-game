ALIAS GAME

Файлы игры:
- index.html — главный экран
- style.css — оформление
- app.js — логика игры
- words.json — список слов по уровням сложности

Запуск:
1. Распакуйте ZIP.
2. Откройте папку в VS Code.
3. Запустите index.html через Live Server.

Важно: игра загружает слова из words.json через fetch(), поэтому обычное открытие index.html двойным кликом (file://) может не работать. Для текущей версии используйте Live Server или другой локальный веб-сервер.

Список слов можно менять непосредственно в words.json.
